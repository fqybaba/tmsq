## 为什么要自己写

LessWrong 2026 年 3 月 14 日的政策（原文见提纲第八节）：
- "LLM 写、人改"的文字算 LLM output，必须放进 LLM content block。
- 自动检测超过阈值会被自动拒稿。
- 对首次发帖的人，接近"零 LLM 文字"。
- 允许：用 LLM 做研究、查资料、写代码；用母语写好后，让 LLM 逐字直译，不改写、不润色。
- 政策原文："If you 'borrow language' from the LLM, that no longer counts as 'text written by a human'."
  管理员在评论里解释，这指的是照搬整个短语，而不是用到某个术语；他举的例子是 ChatGPT 和 Claude 爱用的那种小标题。

所以 `02` 和 `03` 只能用来看，不能把句子改一改就用。政策明确说，借助 LLM 研究得到的事实、论证和例子，由你自己写出来就不算 LLM output。按我们的理解，数字、图和引文信息属于这一类，可以用。这一点是推断，政策没有逐项列出。提纲里的表格，建议你自己重排、自己写表头和说明。

## 建议的写法

1. 先通读 `01_outline_zh.md`，回答每节末尾"你来决定"的问题。
2. 用中文自己写，目标总长折合英文 1,500–2,000 词，相当于中文约 3,000–4,000 字。各节的建议篇幅写在提纲标题里。
3. 写完一节可以发给我。我只指出事实错误、范围说过头、数字对不上、结构问题，不替你改写句子。
4. 全部写完后，让 LLM 做逐字直译（提示词里写明"word-for-word translation, no rewriting, embellishment or tweaks"），再由你通读一遍英文。
5. 发帖前，我再把英文稿里的每个数字对一遍源文件。
